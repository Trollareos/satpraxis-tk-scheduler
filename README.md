# Satpraxis TK Scheduler

Τοπική εφαρμογή Windows που διαβάζει πρόγραμμα από Google Sheets και προτείνει τεχνικούς βάσει ταχυδρομικού κώδικα, ημέρας, εργασιών και ιστορικών τάσεων.

**Έκδοση:** 9 · **Κανόνες ΤΚ:** 06/09/2026 · **Ιστορικό NOVA:** έως 03/09/2026.

## Λειτουργίες

- Σύνδεση με το Google Sheet που επιλέγει ο χρήστης σε κάθε εκκίνηση.
- Ανάγνωση ολόκληρου του XLSX workbook για διατήρηση των χρωμάτων και επιλογή της ζητούμενης ημέρας.
- Επιλογή παρόχου NOVA ή Vodafone και προτάσεις μόνο για κόκκινους τεχνικούς.
- Αναγνώριση NOVA από PS/TAS, Vodafone από 1-/VOD/VFS/VF και πράσινες εργασίες με άγνωστο κωδικό. Ο αναγνωρισμένος κωδικός υπερισχύει του χρώματος.
- Αν ο τεχνικός έχει εργασίες, απαιτείται τουλάχιστον μία του επιλεγμένου παρόχου. Οι κενοί τεχνικοί εμφανίζονται για χειροκίνητο έλεγχο.
- Κατάταξη με ίδιο ΤΚ, άμεση/έμμεση συμβατότητα και ιστορικό.
- Αυτόνομη αναζήτηση αντιστοιχίσεων και εισαγωγή τοπικών ενημερώσεων JSON.
- Ανανέωση πρότασης κάθε 60 δευτερόλεπτα και άνοιγμα του ονόματος του τεχνικού στο Sheet.
- Αναγνώριση ημερών με κόμμα, όπως `ΠΕΜ 1,10` στο πρόγραμμα Οκτωβρίου.
- Υποστήριξη μελλοντικών ετών, πλήρων ημερομηνιών και μετάβασης Δεκεμβρίου–Ιανουαρίου.
- Αυτόματη αναγνώριση έτους από τον τίτλο ή τις πλήρεις ημερομηνίες, με πεδίο διόρθωσης του έτους.
- Αλλαγή παρόχου, ημέρας, ΤΚ ή έτους ακυρώνει την παλιά πρόταση και τυχόν ανάγνωση που βρίσκεται σε εξέλιξη.

Η ώρα επιλέγεται χειροκίνητα. Οι μετρητές εργασιών εμφανίζονται ενημερωτικά και η εφαρμογή δεν εγγυάται ελεύθερο χρονικό slot.

Η προτεραιότητα ίδιου/άμεσου/έμμεσου ΤΚ χρησιμοποιεί τις εργασίες του επιλεγμένου παρόχου. Οι γεωγραφικοί αποκλεισμοί και οι μετρητές εξετάζουν όλες τις εργασίες της ημέρας. Το ιστορικό, οι τάσεις ανά τεχνικό και η ειδική προτίμηση 106xx/114xx παραμένουν μόνο στη NOVA. Οι κοινοί κανόνες ΤΚ εφαρμόζονται και στη Vodafone, αλλά δεν προστίθενται ιστορικές μετρήσεις Vodafone ή νέα όρια φόρτου χωρίς επιβεβαιωμένους κανόνες.

Στη Vodafone διατηρούνται προς το παρόν το φίλτρο κόκκινων τεχνικών και ο υπάρχων περιορισμός μη πράσινης Horizontal Construction. Ο κενός τεχνικός απαιτεί επιβεβαίωση δυνατότητας ανάληψης Vodafone.

## Δημιουργία της εφαρμογής

Για το build απαιτούνται Node.js **22.13 ή νεότερο** και npm:

```bash
npm ci
npm test
npm run build
```

Το έτοιμο πακέτο δημιουργείται στον φάκελο `dist/Satpraxis_TK_Scheduler_Test_v9/`.

## Χρήση στα Windows

1. Άνοιξε τον φάκελο που δημιουργήθηκε στο `dist` ή αντέγραψέ τον ολόκληρο στον υπολογιστή χρήσης.
2. Κάνε διπλό κλικ στο `Start_Satpraxis_Scheduler_Test.bat`.
3. Κράτησε ανοιχτό το παράθυρο του server.
4. Επικόλλησε το Google Sheets link και πάτησε **Σύνδεση και φόρτωση**.
5. Διάλεξε **NOVA / Vodafone**, ημέρα, γράψε ΤΚ και πάτησε **Βρες τεχνικό**.

## Έτη και μελλοντικά προγράμματα

Η αναγνώριση ημερών δεν περιορίζεται στο 2026. Υποστηρίζονται ονόματα όπως `2.11`, `2,11`, `2/11`, `2.11.2027`, `2/11/27` και `2027-11-02`.

Οι πλήρεις ημερομηνίες των φύλλων καθορίζουν το έτος και υπερισχύουν της ρύθμισης. Αν δεν υπάρχουν, το app αναγνωρίζει το έτος από τίτλους όπως `ΝΟΕΜΒΡΙΟΣ 27.xlsx` ή `Πρόγραμμα 2027`. Χωρίς διαθέσιμη ένδειξη χρησιμοποιείται το τρέχον έτος του υπολογιστή. Οι διψήφιοι αριθμοί έτους αναπτύσσονται στον πλησιέστερο αιώνα προς το έτος αναφοράς.

Στη **Σύνδεση spreadsheet / αλλαγή μήνα**, έλεγξε το **Έτος προγράμματος** και διόρθωσέ το αν χρειάζεται. Η αλλαγή ενημερώνει τη λίστα από τον ήδη φορτωμένο κατάλογο και κρύβει το προηγούμενο αποτέλεσμα. Το **Αυτόματο έτος** επαναφέρει την αναγνώριση. Η χειροκίνητη επιλογή ισχύει μέχρι να πατηθεί αυτό το κουμπί ή να κλείσει η εφαρμογή.

Σε πρόγραμμα με φύλλα χωρίς έτος που περνά από Δεκέμβριο σε Ιανουάριο, το πεδίο αφορά το έτος των πρώτων ημερών: τα φύλλα πρέπει να είναι σε χρονική σειρά. Το app προχωρά στο επόμενο έτος κατά τη χειμερινή μετάβαση. Οι πραγματικές ημερομηνίες ελέγχονται και για δίσεκτα έτη.

Τα νέα spreadsheets πρέπει να διατηρούν τη βασική διάταξη στηλών και τη σημασία των χρωμάτων. Η υποστήριξη νέων ετών δεν ανανεώνει αυτόματα τους κανόνες ΤΚ ή το ιστορικό NOVA.

Ο υπολογιστής χρήσης χρειάζεται Windows με PowerShell και Internet για ανάγνωση του Google Sheet. Δεν χρειάζεται Node.js όταν χρησιμοποιείται ήδη δημιουργημένο πακέτο. Ο server ακούει μόνο στο `127.0.0.1`, σε ελεύθερη θύρα από 8765 έως 8775.

Το Google Sheet πρέπει να είναι αναγνώσιμο από τον υπολογιστή με την υπάρχουσα μέθοδο εξαγωγής. Δεν εισάγονται διαπιστευτήρια Google μέσα στην εφαρμογή.

## Δομή κώδικα

| Αρχείο | Ρόλος |
| --- | --- |
| `src/app.ts` | UI, ενημερώσεις JSON και ροή αναζήτησης |
| `src/tk-data.ts` | Αυτόνομη βάση κανόνων ΤΚ |
| `src/recommend.ts` | Αξιολόγηση και κατάταξη τεχνικών |
| `src/xlsx.ts` | Ανάγνωση XLSX, χρωμάτων, τεχνικών και παρόχων |
| `src/sheets.ts` | Αναγνώριση spreadsheet και ημερήσιων φύλλων |
| `src/history-data.json` | Συγκεντρωτικές μετρήσεις ανά τεχνικό και ΤΚ |
| `src/template.html`, `src/styles.css` | HTML και CSS |
| `server.ps1` | Τοπικός server και αναγνώσεις Google Sheets |
| `build.mjs` | Δημιουργία του έτοιμου πακέτου |

**Τεχνολογίες:** TypeScript, HTML, CSS, PowerShell, fflate και esbuild.

## Έλεγχοι

Το `npm test` εκτελεί τους ελέγχους ΤΚ, τους επιχειρησιακούς κανόνες, τη λειτουργία Vodafone, τον parser παρόχων/χρωμάτων, τις ημερομηνίες μελλοντικών ετών και τη ροή επιλογής/ανανέωσης παρόχου και έτους στο UI, χωρίς πρόσβαση σε εταιρικά spreadsheets. Περιλαμβάνει αναγνώριση τίτλων, πλήρεις ημερομηνίες, Δεκέμβριο–Ιανουάριο, αλλαγή ρολογιού στο νέο έτος, δίσεκτα έτη, αντιγραφή ημερομηνίας και ακύρωση εκκρεμών αιτημάτων. Τα fixtures είναι συνθετικά και δεν περιέχουν στοιχεία πελατών.
Το `npm test` εκτελεί τους ελέγχους ΤΚ, τους επιχειρησιακούς κανόνες, χωρίς πρόσβαση σε εταιρικά spreadsheets.

Οι παλαιότεροι έλεγχοι με πραγματικά workbooks διατηρούνται στο `tests/manual/`. Απαιτούν ξεχωριστά τοπικά αρχεία και δεν αποτελούν μέρος του `npm test`.

## Δεδομένα και ενημερώσεις

Η εφαρμογή χρησιμοποιεί αναγνώσεις GET και δεν γράφει στο Google Sheet. Το link του spreadsheet δεν αποθηκεύεται μεταξύ εκκινήσεων. Οι εισαγόμενοι κανόνες JSON αποθηκεύονται στο localStorage του browser.

Το ιστορικό περιλαμβάνει ονόματα τεχνικών και συγκεντρωτικές μετρήσεις, χωρίς στοιχεία πελατών. Τα πρωτογενή spreadsheets δεν περιλαμβάνονται στο repository.

Η εφαρμογή δεν εξαρτάται από τον φάκελο ή το repository του online TK Finder. Οι κανόνες ΤΚ διατηρούνται εδώ στο `src/tk-data.ts` και ενημερώνονται παράλληλα με το αντίστοιχο αρχείο της online εφαρμογής.
