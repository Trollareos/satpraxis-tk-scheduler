# Satpraxis TK Scheduler

Τοπική εφαρμογή Windows που διαβάζει πρόγραμμα από Google Sheets και προτείνει τεχνικούς βάσει ταχυδρομικού κώδικα, ημέρας, εργασιών και ιστορικών τάσεων.

**Έκδοση:** 7 · **Κανόνες ΤΚ:** 06/09/2026 · **Ιστορικό:** έως 03/09/2026.

## Λειτουργίες

- Σύνδεση με το Google Sheet που επιλέγει ο χρήστης σε κάθε εκκίνηση.
- Ανάγνωση ολόκληρου του XLSX workbook για διατήρηση των χρωμάτων και επιλογή της ζητούμενης ημέρας.
- Προτάσεις για κόκκινους τεχνικούς, με αναγνώριση NOVA/Vodafone και λειτουργικών σημειώσεων.
- Κατάταξη με ίδιο ΤΚ, άμεση/έμμεση συμβατότητα και ιστορικό.
- Αυτόνομη αναζήτηση αντιστοιχίσεων και εισαγωγή τοπικών ενημερώσεων JSON.
- Ανανέωση πρότασης κάθε 60 δευτερόλεπτα και άνοιγμα του ονόματος του τεχνικού στο Sheet.

Η ώρα επιλέγεται χειροκίνητα. Οι μετρητές εργασιών εμφανίζονται ενημερωτικά και η εφαρμογή δεν εγγυάται ελεύθερο χρονικό slot.

## Δημιουργία της εφαρμογής

Για το build απαιτούνται Node.js **22.13 ή νεότερο** και npm:

```bash
npm ci
npm test
npm run build
```

Το έτοιμο πακέτο δημιουργείται στον φάκελο `dist/Satpraxis_TK_Scheduler_Test_v7/`.

## Χρήση στα Windows

1. Άνοιξε τον φάκελο που δημιουργήθηκε στο `dist` ή αντέγραψέ τον ολόκληρο στον υπολογιστή χρήσης.
2. Κάνε διπλό κλικ στο `Start_Satpraxis_Scheduler_Test.bat`.
3. Κράτησε ανοιχτό το παράθυρο του server.
4. Επικόλλησε το Google Sheets link και πάτησε **Σύνδεση και φόρτωση**.
5. Διάλεξε ημέρα, γράψε ΤΚ και πάτησε **Βρες τεχνικό**.

Ο υπολογιστής χρήσης χρειάζεται Windows με PowerShell και Internet για ανάγνωση του Google Sheet. Δεν χρειάζεται Node.js όταν χρησιμοποιείται ήδη δημιουργημένο πακέτο. Ο server ακούει μόνο στο `127.0.0.1`, σε ελεύθερη θύρα από 8765 έως 8775.

Το Google Sheet πρέπει να είναι αναγνώσιμο από τον υπολογιστή με την υπάρχουσα μέθοδο εξαγωγής. Δεν εισάγονται διαπιστευτήρια Google μέσα στην εφαρμογή.

## Δομή κώδικα

| Αρχείο | Ρόλος |
| --- | --- |
| `src/app.ts` | UI, ενημερώσεις JSON και ροή αναζήτησης |
| `src/tk-data.ts` | Αυτόνομη βάση κανόνων ΤΚ |
| `src/recommend.ts` | Αξιολόγηση και κατάταξη τεχνικών |
| `src/xlsx.ts` | Ανάγνωση XLSX, χρωμάτων, τεχνικών και παρόχων |
| `src/sheets.ts` | Αναγνώριση spreadsheet και ημερήσιων φύλλων |
| `src/history-data.json` | Συγκεντρωτικές μετρήσεις ανά τεχνικό και ΤΚ |
| `src/template.html`, `src/styles.css` | HTML και CSS |
| `server.ps1` | Τοπικός server και αναγνώσεις Google Sheets |
| `build.mjs` | Δημιουργία του έτοιμου πακέτου |

**Τεχνολογίες:** TypeScript, HTML, CSS, PowerShell, fflate και esbuild.

## Έλεγχοι

Το `npm test` εκτελεί τους ελέγχους ΤΚ, τους επιχειρησιακούς κανόνες, χωρίς πρόσβαση σε εταιρικά spreadsheets.

Οι παλαιότεροι έλεγχοι με πραγματικά workbooks διατηρούνται στο `tests/manual/`. Απαιτούν ξεχωριστά τοπικά αρχεία και δεν αποτελούν μέρος του `npm test`.

## Δεδομένα και ενημερώσεις

Η εφαρμογή χρησιμοποιεί αναγνώσεις GET και δεν γράφει στο Google Sheet. Το link του spreadsheet δεν αποθηκεύεται μεταξύ εκκινήσεων. Οι εισαγόμενοι κανόνες JSON αποθηκεύονται στο localStorage του browser.

Το ιστορικό περιλαμβάνει ονόματα τεχνικών και συγκεντρωτικές μετρήσεις, χωρίς στοιχεία πελατών. Τα πρωτογενή spreadsheets δεν περιλαμβάνονται στο repository.

Η εφαρμογή δεν εξαρτάται από τον φάκελο ή το repository του online TK Finder. Οι κανόνες ΤΚ διατηρούνται εδώ στο `src/tk-data.ts` και ενημερώνονται παράλληλα με το αντίστοιχο αρχείο της online εφαρμογής.
